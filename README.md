# Gameloc

모든 게임을 한번에 딸깍 기계번역 하는 것을 목표로 하고 있습니다.

지원 엔진: RPG Maker · Ren'Py · TyranoScript · Unity

## 쓰는 법

1. 압축을 풀고 `1_install.bat` 을 한 번 실행합니다
2. `2_start.bat` 으로 켭니다
3. 게임 폴더를 넣고 순서대로 누르면 됩니다

지우려면 `3_uninstall.bat` 을 실행합니다.
